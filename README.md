# Simple Calculator Using Python Flask, HTML & CSS

## Project Description

The Simple Calculator is a web-based application developed using Python Flask, HTML, and CSS. It performs basic arithmetic operations such as addition, subtraction, multiplication, and division.

The application provides a simple and user-friendly interface where users can enter two numbers, select an arithmetic operation, and view the calculated result instantly.

## Technologies Used

- **Python:** Used for application logic and calculations.
- **Flask:** Python web framework used to develop the web application.
- **HTML:** Used to create the calculator structure.
- **CSS:** Used to design and style the calculator interface.

## Features

- Addition of two numbers.
- Subtraction of two numbers.
- Multiplication of two numbers.
- Division of two numbers.
- User-friendly interface.
- Displays calculation results.
- Handles division by zero.

## Installation and Setup

**Step 1: Clone the Repository**

```bash
git clone <your-github-repository-url>
```

**Step 2: Navigate to the Project Folder**

```bash
cd simple_calculator_using_python_flask_css_html
```

**Step 3: Install Flask**

```bash
pip install flask
```

**Step 4: Run the Application**

```bash
python app.py
```

**Step 5: Open in Browser**

Open the following URL in your web browser:

```text
http://127.0.0.1:5000/
```

## How to Use

1. Open the calculator application in your browser.
2. Enter the first number.
3. Enter the second number.
4. Select the arithmetic operation.
5. Click the Calculate button.
6. View the result on the screen.

## Supported Operations

| Operation | Description |
|---|---|
| Addition (+) | Adds two numbers |
| Subtraction (-) | Subtracts the second number from the first |
| Multiplication (*) | Multiplies two numbers |
| Division (/) | Divides the first number by the second |
